<!-- 'What the numbers mean' paragraph, before the Sensor Tower paragraph -->
**Steam players** (`data/steam_players.json`) is not a revenue layer and is never mixed with one — it's a headcount, from Valve's public `GetNumberOfCurrentPlayers` endpoint (no API key). Three things to know: it counts only players who launched **through Steam**, so mobile, PlayStation and standalone-launcher players are invisible and the number is a **floor** — the gap between two games says as much about how PC-heavy each is as about how big it is; it's **one reading per day at roughly the same wall-clock time** (~00:30 JST), a fixed-time slice rather than the day's peak, which is what makes it comparable day to day; and Valve publishes only the current count, so the **history starts when the scrape did** and cannot be backfilled (SteamDB has the archive but is explicitly not scrapable).
